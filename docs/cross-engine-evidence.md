# Engine capability and comparison policy

`packages/contracts/engine-capabilities.json` is the execution allow-list. Scenario sources and intervention types must both be supported by the chosen engine; an unavailable specialist engine never falls back to WebGL or closed boundaries.

`artifacts/verification/cross-engine-manifest.json` pins the CPU and GPU build-source hashes and their result hashes. It retains engine-native fixture descriptions and labels the comparison as implementation agreement for shared assumptions only. A common visual display never implies identical equations, calibration or observed-event accuracy.
